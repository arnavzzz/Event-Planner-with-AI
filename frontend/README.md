# Event Planner with AI - Frontend Application

This directory contains the React 19 + TypeScript + Vite frontend application for **Event Planner with AI**.

Refer to the main [Root Readme](../Readme.md) for full project details, feature set, role credentials, and overall setup instructions.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run production build
npm run build

# Run Oxlint
npm run lint
```
